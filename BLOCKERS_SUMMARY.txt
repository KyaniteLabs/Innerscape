BLOCKING ISSUE #1: CIRCULAR DEPENDENCY (CRITICAL)
===============================================================================

Location: lifeos-shared/src/storage/syncService.ts

Problem:
  The shared library imports from a specific app (innerscape-soma).
  This creates a circular dependency that prevents the shared library 
  from building, which cascades to all Expo apps.

Error Message:
  "File '/Volumes/.../innerscape-soma/lib/sync/schema.ts' is not under 
   'rootDir' '/Volumes/.../lifeos-shared/src'"

Why This Breaks Everything:
  1. Shared lib tries to build
  2. It references innerscape-soma/lib/sync/schema.ts
  3. That's outside the shared library's scope
  4. Shared lib build fails
  5. All apps depending on shared lib fail to build

Required Fix (30 minutes):
  1. Move innerscape-soma/lib/sync/schema.ts 
     → lifeos-shared/src/schemas/powerSyncSchema.ts
  
  2. Update innerscape-soma to import from @lifeos/shared
  
  3. Remove any ../../../ relative imports from shared library

Impact:
  - BLOCKS Shared library build
  - BLOCKS All Expo app builds (Soma, Mobile)
  - BLOCKS Web app if it depends on shared lib
  - BLOCKS entire launch
